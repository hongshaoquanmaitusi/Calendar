# Calendar — 断电续走的 RTC 电子时钟

基于 RTC 备份域的电子时钟：OLED 三行显示日期、星期与时间，EC11 旋转编码器完成参数设置的完整人机交互，纽扣电池保证断电后走时不丢。

## 系统架构

```
EC11 编码器（EXTI + 三回调 API）
   ▼
UI 状态机：浏览 / 设置 双模式 × 年月日时分秒六字段
   │  settingTime 为编辑草稿，保存时一次性写入 RTC（草稿-提交模式）
   ▼
new_rtc 模块：mktime/gmtime ⇄ Unix 时间戳 ⇄ RTC 32 位秒计数器
   │  LSE 32.768kHz → 1Hz，VBAT 备份域供电
   ▼
OLED（I²C + 帧缓冲三连刷新）
```

## 亮点

- **备份域电源管理**：备份寄存器标志位跳过重复初始化；定位并修复"RTC 时钟源误配为内部 LSI 导致断电停走"的隐蔽故障——用"复位/断电分离实验 + 断电三症状判读"锁定病位，完成 LSE 切换与断电验证
- **嵌套状态机 UI**：双模式 × 六字段，光标闪烁指示编辑位，按键含义由两层状态共同决定
- **Unix 时间戳体系**：C 标准库与 RTC 计数器同构，历法换算全部交给 mktime/gmtime

## 硬件与开发环境

- STM32F103C8T6（波特律动学习板：CR1220 备份电池 + 32.768kHz 晶振 + EC11 编码器 + 0.96" OLED）
- STM32CubeMX + STM32CubeIDE + HAL 库

## 目录结构

```
App/    task_main.c 业务层（状态机 + UI + 按键回调）
Lib/    new_rtc.c 模块（备份域初始化、跨时钟域读写、防撕裂双读）
Core/   CubeMX 生成代码
```
